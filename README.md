# ⚡ zivv — تواصل اجتماعي بذكاء وخصوصية

**الرؤية:** فيسبوك + واتساب + تيك توك + مساعد ذكي، بواجهة سوداء تركوازية.
**الطريقة:** كل صفحة = 3 ملفات منفصلة (HTML + CSS + JS) مربوطة بموقع واحد. مرحلة بمرحلة.

## 📁 هيكل المشروع

```
zivv/
├── index.html      ← المرحلة 1 ✅ صفحة تسجيل الدخول (الـ Landing)
├── home.html       ← المرحلة 2 ⏳ الرئيسية (نسخة مؤقتة — هنبنيها كاملة)
├── css/
│   ├── login.css   ← تنسيقات تسجيل الدخول
│   └── home.css    ← تنسيقات الرئيسية
├── js/
│   ├── login.js    ← منطق تسجيل الدخول (OTP + تحقق + جلسة)
│   └── home.js     ← منطق الرئيسية (مؤقت)
└── README.md
```

## ✅ المرحلة 1 — تسجيل الدخول (منفذة بالكامل)

حسب وثيقة المتطلبات:
- أول صفحة تظهر هي تسجيل الدخول ✅
- تسجيل بالبريد الإلكتروني فقط (مفيش Google) ✅
- إنشاء حساب: الاسم الأول + اسم العائلة + العمر + الإيميل ✅
- منع أقل من 18 سنة ⛔ ✅
- OTP: رمز 6 أرقام، صلاحية 10 دقائق، حد 5 محاولات + قفل 60 ثانية ✅
- إعادة إرسال بعد كولداون 60 ثانية ✅
- المفاتيح (RESEND_API_KEY...) مش في الواجهة ✅

**🧪 وضع التطوير:** مفيش سيرفر لسه، فالمستخدمين بيتخزنوا في localStorage
والرمز بيظهر في شارة بنفسجية. في المرحلة 11-12 هيتشال ويتحط سيرفر حقيقي.

## ▶️ التشغيل

من الفولدر: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`
أو افتح `index.html` مباشرة في المتصفح.

## 🔒 الأمان (من الوثيقة)

- لا توضع المفاتيح في index.html أو app.js أو styles.css أبدًا
- رمز OTP: hash في القاعدة + صلاحية + منع سبام (حد المحاولات)
- بيانات المالك مشفرة في القاعدة، مش في الواجهة
